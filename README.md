# 🎁 Secret Santa Generator (MERN Stack)

## 📌 Project Overview
This application automates the Secret Santa assignment process for employees.

It ensures:
- No employee is assigned to themselves
- No employee gets the same secret child as last year
- Each employee has exactly one secret child
- Each secret child is assigned only once

---

## 🛠 Tech Stack

Frontend:
- React
- Axios
- CSS

Backend:
- Node.js
- Express.js
- Multer (File Upload)
- csv-parser
- json2csv
